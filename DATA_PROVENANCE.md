# Data provenance

This file says where every kind of data used by this project comes from, so that
nothing in the repository is mistaken for something it is not.

## In the repository today

The repository contains **no surveillance data**. Tests create a handful of
invented rows (for example an org unit called "Bo" with a made-up series) purely
to check database constraints. They do not describe real places or real counts.

## Planned sources

| Source | Used for | Nature | Licence and terms |
|---|---|---|---|
| Public DHIS2 demo instance (`play.im.dhis2.org`) | Exercising the sync against a real DHIS2 API | Demonstration data published by the DHIS2 project. **Not real surveillance data** | Subject to the DHIS2 demo terms; used read-only |
| Synthetic series generator | Testing and evaluating detection algorithms | Generated: seasonal baseline plus Poisson noise plus a controlled injected outbreak. Fully reproducible from a documented random seed | Generated by this project, Apache-2.0 |

Credentials for any external instance are read from environment variables and are
never committed.

## Refresh and reproducibility

- Synthetic data is regenerated from its seed; the seed is recorded next to every
  reported result.
- Data pulled from the demo instance is fetched on demand and is not committed to
  the repository. Its provenance (instance URL, version, time of retrieval) is
  recorded with each sync run.

## What this project will never contain

Real patient records, case-level line lists, or data obtained from any real
health facility or programme. See [ETHICS.md](ETHICS.md).
