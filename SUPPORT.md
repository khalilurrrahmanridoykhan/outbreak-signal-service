# Getting help

- **How do I...? Does it support...?** Ask in
  [Discussions](https://github.com/khalilurrrahmanridoykhan/outbreak-signal-service/discussions).
- **Something is broken:** open a [bug report](https://github.com/khalilurrrahmanridoykhan/outbreak-signal-service/issues/new?template=bug_report.yml).
- **I have an idea:** start a Discussion first, or file a
  [feature request](https://github.com/khalilurrrahmanridoykhan/outbreak-signal-service/issues/new?template=feature_request.yml).
- **Security concern:** follow [SECURITY.md](SECURITY.md), never a public issue.

This project has one maintainer and no commercial support. Replies are best
effort.
